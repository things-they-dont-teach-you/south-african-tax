# South African tax

How personal tax works in South Africa, taught by your AI assistant: brackets, your payslip,
filing a return, paying less tax legally, freelance income and dealing with SARS.

Part of [Things They Don't Teach You in School](https://github.com/things-they-dont-teach-you).
Easiest start: the [enrol](https://github.com/things-they-dont-teach-you/enrol) repo, which sets
up this course for you.

## Start on its own

```sh
git clone https://github.com/things-they-dont-teach-you/south-african-tax.git
cd south-african-tax
claude
```

Codex and Gemini CLI work too. Say hello and the tutor takes it from there.

## This is not tax advice

This course explains how the system works. For your own situation, use a registered tax
practitioner. Always confirm figures on [sars.gov.za](https://www.sars.gov.za) before you act.
